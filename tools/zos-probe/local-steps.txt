# ローカルで流すステップの表。実機の実行用 JCL (jcl/PRBRUN*.jcl, PRBABND.jcl)
# のステップと 1 対 1 に対応させ、ステップ名を揃える。ProbeTool prb は
# 「ステップ名 + 事例名」で突き合わせるからである。
#
# 形: ジョブ ステップ プログラム [SYSIN の中身 (\n で行を分ける)]
#
# 翻訳の変種 (CBLNUMP など) は、ここでは元のプログラムを流す。この処理系は
# NUMPROC(PFD/MIG) を断り、ADV / NUMBER / RENT を読まないので (P-023)、変種を
# 作っても同じクラスになる。実機の変種との差が、そのまま「効いていない
# オプション」の証拠になる。
# CEEOPTS の変種 (WSI2, WSI4, DBG2, DBG4) も同じ理由で元と同じに流す。
# ただし SSRANGE と ARITH(EXTEND) はこの処理系でも効くので、「プログラム@オプション」と書いて
# そのオプションで翻訳し直したものを流す (run-local.sh)。
