## 1. 概要と進捗サマリ

本プロジェクト「`cobol-on-java`」は、IBM メインフレーム上の COBOL 資産をソースコード無修正で JVM 上へ移行可能とすることを目的とした COBOL 処理系（コンパイラ・ランタイム）の開発プロジェクトです。

2026年9月4日現在の調査により、**要件定義（要件定義書 v0.5, 全決定事項 D-1〜D-19 確定）**を完了し、**開発フェーズ P0-a (ランタイム先行)**、**V2 検証オラクル基盤 (Hercules 連携)**、および **P0-b (コンパイラ・処理系)** の主要機能が実装済みであることが確認されました。また、当初 P1 フェーズ予定であった**ファイル入出力機能（順編成・相対編成・索引編成）**についても先行して実装・検証が進んでいます。

* **構文解析 (`dev.cobolonjava.compiler.parser`)**:

  * [`ProcedureBuilder`](file:///d:/workspace/cobol-on-java/cobol-compiler/src/main/java/dev/cobolonjava/compiler/semantic/ProcedureBuilder.java): 一意名解決、段落・セクション制御構造構築。
* **ASM コード生成 (`dev.cobolonjava.compiler.codegen`)**:
  * Java ソース生成ではなく ASM による JVM バイトコード直接生成（D-3 / ARC-3）。生成クラスは `main(String[] args)` を持ち直接起動可能。
  * **対応文（動詞）**: `MOVE` (含む `CORRESPONDING`), `ADD`, `SUBTRACT`, `MULTIPLY`, `DIVIDE`, `COMPUTE`, `ON SIZE ERROR`, `IF`, `EVALUATE`, `PERFORM` (含む `VARYING`, `THRU`), `GO TO` (P-029解消済), `CALL` (含む `RETURN-CODE`), `INITIALIZE`, `SEARCH` / `SEARCH ALL` (二分探索、P-036解消済), `ACCEPT`, `DISPLAY`, `INSPECT`, `STRING`, `UNSTRING`, `SPECIAL-NAMES`, ファイル I/O 文 (`OPEN`, `CLOSE`, `READ`, `WRITE`, `REWRITE`, `DELETE`), `SSRANGE` 範囲検査。

### 3.3 `cobol-oracle`（検証オラクル基盤）

* **Hercules 連携機構**:
  * 外部アセンブラ非依存のバイナリエンコーダ (`Insn`, `EditMask`) により z/Architecture 命令列を直接ビルド。`.tst` / `loadcore` 機構を介して Hercules 上で実行し、メモリ結果を取得（D-11, D-11b）。
* **合成テストジェネレータ (Pairwise Testing)**:
  * 境界値および組み合わせ軸（USAGE × 演算 × 丸め × SIZE ERROR）を縮約抽出し、485 通りのテストパターンを自動生成して実行結果を照合（NFR-041 / D-15）。
